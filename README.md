# 实验：双盲 A/B（仓位控制 vs 无仓位控制）

## 实验概况

- 实验类型：双盲 A/B 对照实验
- 时间：请在下方填写实验期间（例如：2026-05-xx 至 2026-06-xx）
- 资金规模：两个相同账户，初始资金均为 1,000,000 人民币
- 对照设定：
  - A（启用仓位控制模块）

## 目的

验证在相同市场周期与相同资金下，是否启用仓位/仓位控制模块会导致策略表现上有显著差异。
